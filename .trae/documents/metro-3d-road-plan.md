# 地铁线路立体效果实施计划

## Context

当前 3D 地铁线路是贴地、4 像素的 Cesium polyline。用户希望保持现有地图与交互不变，只为线路增加立体观感。线路颜色、高亮、站点详情中的来源线路保留状态以及相机返回行为均需保持既有语义。

## 推荐方案

保留现有贴地 polyline 作为线路底层和业务拾取对象，在其上叠加一个轻微离地、窄圆管形的 Cesium PolylineVolume 视觉层。该增强层作为道路实体管理，但不承载业务拾取身份；线路显隐、选中态和上下文线路高亮都同步控制增强层。厚度与抬升采用小幅固定值，避免粗管造成穿地与遮挡。若 Cesium 的地形/急弯表现验证不可靠，则使用稍微加宽并有深浅层次的贴地线作为实现回退，不改变现有业务结构。

增强层只作用于 3D 地铁路线；站点、2D 模式、路线数据、选择/定位流程及相机状态不调整。

## 实施步骤

1. 在 `roads.ts` 的 `RoadRenderOptions` 增加立体层所需的最小配置，保留当前基础线宽、贴地属性与颜色默认值；由 `createRoadEntities` 为每个有效线路片段创建稳定 ID 的增强实体，并保留现有主实体 ID、segment ID 与返回值。
2. 确认增强实体不会被 `bizKeyOf` 误识别为独立业务对象；扩大道路图层显隐筛选以覆盖增强层，同时保持线路点击仍解析为原道路对象。
3. 在 `Map3DEngine.ts` 中维护每个增强实体对应的原材质快照；修改 `refreshHighlight` 和 `setContextRoad`，使基础线及增强层同步显示选中/上下文色，恢复时互不覆盖并回到原线路色。清理时恢复样式并随 Viewer 生命周期释放实体。
4. 检查线路隐藏/显示、选中线路与站点上下文线路相同、切换另一条线路、清除选中等顺序，避免叠加层遗留高亮或改变近期相机恢复行为。
5. 若需要将增强参数从引擎构造传入，在 `MapContainer.vue` 使用现有 `RoadRenderOptions` 参数通道；不新增用户界面或全局状态。

## 关键文件

- `smarttran/src/map3d/entities/roads.ts`：线路实体和渲染参数。
- `smarttran/src/map3d/Map3DEngine.ts`：实体可见性、选中/上下文样式与销毁清理。
- `smarttran/src/components/map/MapContainer.vue`：仅在需要时传递 3D 渲染参数，保留状态回放逻辑。

## 验证

- 运行 `npm run type-check`、`npm run build` 和 `git diff --check`。
- 在 3D 模式检查不同俯仰角下的立体感、线路急弯、密集交汇和地形区域，确认没有明显穿地、跳变或线路间遮挡。
- 验证道路图层开关、线路点选/取消、站点详情中的线路上下文高亮和返回；确认返回位置与视角保持不变。
- 检查 2D 模式和非路线实体没有视觉或交互回归，并观察大量线路实体的渲染性能。
