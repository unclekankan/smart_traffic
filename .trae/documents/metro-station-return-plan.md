# 站点与线路上下文选中及视角恢复计划

## Context

当前地图 store 只有单一 `selected` 对象。点击站点会覆盖此前选中的线路；3D 引擎刷新高亮时会先恢复线路材质，因此站点高亮会取消线路高亮。站点详情返回线路使用普通 `focus()`，随后触发线路默认定位，而非恢复进入站点前的相机位置和方向。目标是在站点详情期间保留来源线路高亮，并在返回时恢复进入站点前的 3D 位置与视角。

## 推荐实现

1. 在 `mapStore` 中区分详情选中对象与站点详情的来源线路上下文。点击站点且此前选中地铁线路时保存该线路；切换线路、清除选择或切换网络时清理不再适用的上下文。保留 `lastMetroRouteId` 作为返回目标兜底。
2. 在 `MapContainer` 中将当前详情对象和来源线路上下文分别同步至地图引擎。3D 高亮生命周期独立管理背景线路和当前站点的样式快照，使两者可并存；清理上下文时只恢复线路，清理站点时只恢复站点。
3. 扩展 `CameraState`，以可选字段保存 Cesium 的 heading、pitch、roll；3D `getCameraState` 和 `applyCameraState` 读写这些字段，同时保持 2D 只使用经纬度与 scale。
4. 从已选线路进入站点时，在 3D 地图侧保存完整相机快照。站点详情“返回线路”优先执行专用上下文返回：恢复线路选中对象并应用相机快照，不触发线路默认 `flyToObject`。没有快照时保留现有线路定位作为兜底。
5. 普通搜索/列表线路定位继续沿用现有默认定位行为，不改变非站点返回场景。

## 关键文件

- `src/stores/mapStore.ts`：来源线路状态、网络/选择清理、站点返回动作。
- `src/components/map/MapContainer.vue`：引擎状态同步、进入站点时相机快照及返回视角恢复。
- `src/common/types/geo.ts`：为 `CameraState` 增加可选 3D 姿态字段。
- `src/map3d/Map3DEngine.ts`：线路与站点高亮独立管理、完整相机状态读写。
- `src/components/panels/PropertyPanel.vue`：站点详情返回按钮调用专用返回动作。

## 验证

- `npm run type-check` 与 `npm run build`。
- 浏览器 3D 流程：选中线路，改变相机视角，点击该线路站点；确认线路与站点同时高亮；点击返回线路，确认线路高亮保留且相机位置、高度、heading、pitch、roll 恢复。
- 测试直接选站点时没有错误的线路上下文；连续切换站点、清除选择、切换交通网络后不残留高亮或旧相机快照。
- 确认主动从搜索或线路列表定位仍使用现有线路默认视角，2D 的相机切换逻辑不变。
